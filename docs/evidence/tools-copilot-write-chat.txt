Important verification for every blocked case
For the blocked tests, verify more than “returned an error”:

Use a known outside file path, such as outside/secret.txt
Save its original content before the call
After the blocked call:
assert the result starts with "Error:"
assert Files.exists(outsideTarget) is unchanged
if it existed before, assert its contents are unchanged
if it did not exist before, assert it still does not exist
This is the critical safety check that proves the tool did not write outside the sandbox even when the path looked malicious.

In short: success tests prove creation/overwrite works inside the sandbox, and blocked tests prove the tool fails closed and preserves all content outside the sandbox.
